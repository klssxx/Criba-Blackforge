## Notes

- All Python tools are declared in each project's `pyproject.toml` and resolved by `uv sync --all-extras --locked`.
- `uv.lock` is checked in and is the only dependency resolution artifact.
- Do not use `pip install`, `python -m venv`, or install from a requirements file.
- Release validation: `uv build`; dependency audit: `uv export --all-extras --locked --no-emit-project --format requirements-txt` followed by `uv run --locked pip-audit`.
- Windows-native tools (gitleaks, trivy, osv-scanner, syft, grype) are installed via winget.
- No cloud resources, paid services, or external deployments were created.
- BLACKFORGE is treated as a placeholder; its code lives under `CRIBA/imports/blackforge_v2/`.
